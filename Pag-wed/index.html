¿Qué es la Estructura HTML5?

HTML5 introdujo etiquetas semánticas avanzadas que permiten definir claramente las distintas partes de una página web tanto para los navegadores como para los desarrolladores.

Etiquetas Clave de HTML5

<header>

Representa un contenedor de contenido introductorio o un grupo de enlaces de navegación. Suele incluir el logotipo y el título principal.

<nav>

Sección de una página cuyo propósito es proporcionar enlaces de navegación, ya sea dentro del sitio actual o hacia otros documentos.

<section> y <article>

Section define una sección temática en un documento. Article representa una composición autónoma que podría distribuirse de manera independiente (como un post de blog o noticia).

Nuevas Extensiones Semánticas Avanzadas

<figure> y <figcaption>

Utilizadas para asociar contenido visual (como imágenes, diagramas o códigos) con su respectiva leyenda o pie de nota de manera semántica.

<details> y <summary>

Permiten crear un widget interactivo desplegable nativo sin necesidad de utilizar JavaScript para mostrar u ocultar información adicional.
